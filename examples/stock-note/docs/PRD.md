# PRD: 재고노트 (stock-note)

## 목표
카페 점주가 월말 재고와 입고량만 입력하면 품목별 월·일 사용량을 확인하고, 발주일(수요일·목요일)을 놓치지 않게 한다.

## 사용자
- **점주**: 본사에서 원재료를 공급받는 카페 매장의 운영자. 매장마다 계정이 1개이고 주로 휴대폰으로 쓴다.
- **본사 담당자**: 점주가 보낸 문의·불만을 확인하고 매장 계정을 발급한다.

이 웹 버전은 정식 출시 전 MVP다. 웹으로 먼저 내고 점주 피드백을 모은 뒤 React Native로 정식 버전을 만든다.

## 핵심 기능
1. **월말 재고 입력** — 한 화면에서 9개 품목의 월말 재고를 입력한다. 이미 시작된 달만 입력할 수 있고, 저장한 뒤에도 고칠 수 있다. 말일부터 입력할 때까지 홈에 입력 안내를 띄운다.
2. **입고 기록** — 입고된 날짜와 품목별 수량을 기록한다. 수량을 적은 품목만 저장한다. 목록에서 고치거나 지울 수 있고, 미래 날짜는 입력할 수 없다.
3. **사용량 조회** — 홈에서 달을 골라 품목별 월 사용량과 하루 평균 사용량을 표로 본다. 기본으로 직전 달을 보여준다.
4. **발주일 알림** — 매주 수요일과 목요일 09:00(KST)에 "오늘은 발주일입니다. 재고를 확인하고 발주하세요." 푸시 알림을 보낸다. 설정에서 켜고 끈다. 발주일에는 홈 상단에도 같은 문구의 배너를 보여준다.
5. **문의·불만 접수** — 점주가 보는 모든 페이지에 문의 버튼이 있다. 유형(문의/불만)과 내용(1,000자 이내)을 적어 보내면 보낸 페이지 경로와 매장이 함께 저장된다. 로그인 페이지에서는 매장명과 연락처를 추가로 받는다.
6. **본사 관리자 화면** — 문의 목록을 최신순으로 보고 유형·상태로 걸러 보며, 접수/처리완료 상태를 바꾼다. 매장 계정을 만들고 비밀번호를 재설정한다.
7. **로그인** — 본사가 발급한 아이디와 비밀번호로 로그인한다. 점주는 설정에서 비밀번호를 바꿀 수 있다.

## 품목
본사가 공식 공급하는 9개 품목으로 고정한다. 품목을 추가하거나 고치는 화면은 없다.

| 코드 | 품목 | 단위 (가정) |
|------|------|------|
| milk | 우유 | 팩(1L) |
| coffee-beans | 원두 | kg |
| matcha-powder | 말차 파우더 | 봉 |
| iced-tea-powder | 아이스티 파우더 | 봉 |
| vanilla-syrup | 바닐라 시럽 | 병 |
| chocolate-syrup | 초콜릿 시럽 | 병 |
| mango-syrup | 망고 시럽 | 병 |
| blue-curacao | 블루 큐라소 | 병 |
| lemon-extract | 레몬 농축액 | 병 |

수량은 0 이상이고 소수 첫째 자리까지 입력한다 (예: 반 병 = 0.5).

## 사용량 계산 규칙
- 월 사용량 = 전월 말 재고 + 당월 입고량 합계 − 당월 말 재고
- 하루 평균 사용량 = 월 사용량 ÷ 그 달의 일수 (달력 기준), 소수 첫째 자리로 반올림

예: 10월 우유. 9월 말 재고 12팩, 10월 입고 80팩, 10월 말 재고 10팩이면 월 사용량은 12 + 80 − 10 = 82팩, 하루 평균은 82 ÷ 31 = 2.6팩이다.

| 상황 | 화면 표시 |
|------|------|
| 전월 말 재고가 없다 (첫 입력 달) | 사용량 대신 "다음 달부터 계산됩니다" |
| 당월 말 재고를 아직 입력하지 않았다 | 사용량 대신 "월말 재고 입력 필요" |
| 계산 결과가 음수다 | 사용량 대신 "확인 필요 — 입고 기록이 빠졌는지 확인하세요" |
| 그 외 | 월 사용량과 하루 평균 |

처음 입력한 월말 재고는 기준 재고가 되고, 사용량은 그다음 달부터 나온다.

## 확인이 필요한 가정
본사 확인 전까지 아래 값으로 만든다.
- 품목별 단위는 위 표와 같다.
- 하루 평균은 영업일이 아니라 달력 일수로 나눈다.
- 알림 시각은 09:00(KST)이고 모든 매장에 같은 문구를 보낸다.
- 문의 버튼은 본사 관리자 화면에는 두지 않는다.

## MVP 제외 사항
- 앱 안에서 발주하기, 발주량 추천
- 품목 추가·수정
- 차트 (표만 제공)
- 문의에 대한 앱 내 답변 (본사가 전화·메일로 답한다)
- 점주 직접 가입, 매장당 여러 계정
- 월말 재고 입력 알림 등 발주일 외의 푸시 알림
- 엑셀 내보내기
- 비로그인 문의의 횟수 제한 (내용 길이만 제한한다)
- React Native 앱

## 디자인
- 휴대폰 화면 우선, 라이트 모드 고정. 숫자를 빨리 입력하고 빨리 읽는 도구.
- 무채색(stone) + 포인트 1가지(emerald). 자세한 값은 UI_GUIDE를 따른다.
