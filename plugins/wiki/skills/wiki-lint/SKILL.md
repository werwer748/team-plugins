# wiki-lint

위키 전체를 점검해서 보고서를 먼저 보여준다. 수정은 사용자가 승인한 뒤에 한다.

## 시작 전에

1. **vault 확인.** 현재 폴더에 `raw/`와 `wiki/`가 있는지 본다. 없으면 여기는 위키 vault가 아니라고 알리고 멈춘다.
2. **규칙 읽기.** Skill 도구로 `wiki:wiki-schema`를 불러온다. 무엇이 규칙 위반인지는 그 규칙이 기준이다.

## 점검 항목

1. **모순**: 페이지 사이, 또는 한 페이지 안에서 같은 사실에 대해 값이 다름
2. **낡은 주장**: 이후 소스로 대체됐는데 현재형으로 남아 있는 내용
3. **고아 페이지**: `index.md` 말고는 들어오는 링크가 없는 페이지
4. **깨진 링크**: 존재하지 않는 페이지를 가리키는 링크
5. **빠진 페이지**: 여러 곳에서 언급되지만 자체 페이지가 없는 개념·대상
6. **중복**: 같은 대상을 가리키는 페이지가 둘 이상 (별칭 누락)
7. **출처 누락**: 출처 표시가 없는 사실
8. **미처리 소스**: `raw/`에 있지만 `log.md`에 ingest 기록이 없는 파일
9. **데이터 공백**: 확인이 필요한데 비어 있는 정보. 다음에 조사할 질문이나 찾아볼 소스를 제안한다.

링크와 파일 목록처럼 셀 수 있는 항목(3, 4, 8)은 눈으로 훑지 말고 grep과 파일 목록으로 대조한다.

## 보고서

항목별로 `페이지 — 문제 — 제안` 형식으로 쓴다. 이미 `> [!warning] 모순` callout으로 표시된 모순은 새 발견과 구분해서 "표시됨, 미해결"로 적는다. 해당 사항이 없는 항목은 "없음"이라고 적는다.

## 수정

보고서를 보여준 뒤 어떤 제안을 적용할지 묻는다. 승인받은 것만 고친다. 모순은 소스 없이 한쪽을 골라 해소하지 않는다. 수정하고 나면 `wiki/log.md`에 `lint` 항목으로 기록한다.
